# VP3.me Backend Specification Set

This folder contains the finalized implementation baseline for the VP3.me backend, POD licensing, Stripe billing, provisioning, updates, backups, HomeServer entitlements, security, and production operations.

## Review volumes

- `01-CORE-ARCHITECTURE-CONTRACTS.md` — backend architecture, database schema, API contract, and POD licensing.
- `02-PLATFORM-INTEGRATION-OPERATIONS.md` — HomeServer entitlements, provisioning, releases, updates, backups, security, and testing.
- `03-BILLING-PHASES-AUTHORIZATION.md` — build phases, Stripe, remaining-contract closure, authentication, and authorization.
- `04-JOBS-HOSTING-NOTIFICATIONS-PRIVACY.md` — queues, hosting/DNS/SSL, notifications, audit, privacy, and retention.
- `05-API-DEPLOYMENT-READINESS-HANDOFF.md` — API standards, environments, secrets, production readiness, and implementation handoff.

The model catalog is intentionally excluded.
